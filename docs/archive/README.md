# Archive

Planning and marketing notes from SnapNuts 0.1 (December 2025, the Rectangle +
Hammerspoon hack) and 1.x (January 2026, the native Swift app). Kept for the
record; nothing here describes the current product. The live documentation is
`README.md` and `CHANGELOG.md` at the repo root.

`appcast.xml` stays at the root on purpose: installed copies of the 1.x Swift
app check `raw.githubusercontent.com/GenesisFlowLabs/snapnuts/main/appcast.xml`
for updates, and moving it would turn that check into a 404.
